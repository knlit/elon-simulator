## 🎮 游戏简介

这是一个基于 Web 的单文件策略模拟游戏。你将扮演埃隆·马斯克，体验拥有近乎无限财富的同时，如何在国际地缘政治的夹缝中寻求"完美破产"。

---

## ✨ 核心玩法

**💰 逆向经济系统**
> 你的钱会自动生钱（利息 + 投资回报）。你必须购买高维护费用的资产来制造每秒的巨额亏损。

**🎲 人气悖论**
> 如果你做受欢迎的事（造火箭），股价会上涨，资产不降反升。你必须做一个"混蛋"，购买推特、发疯、得罪人，以压低股价。

**⚠️ 三大风险指标**

| 指标 | 说明 |
|------|------|
| 法律风险 | 烧钱、干预大选会增加风险 |
| 国际紧张度 | 拥有私人武装或宣布火星主权会激怒联合国 |
| 资产冻结 | 达到 100% 游戏结束 |

**🏦 大而不倒机制**
> 如果破产速度过快，政府会强制注资救市，导致你的努力白费。

## 🤖 AI 驱动

- **Grok 顾问**：内置 AI 助手，根据当前财务状况提供毒舌建议
- **动态新闻**：每次购买都由 AI 生成独一无二的国际新闻头条

---

## 🛠️ 技术栈

- HTML5 + Vanilla JavaScript（无框架）
- Tailwind CSS（CDN）
- FontAwesome 图标
- Google Gemini API（文案生成）
- Pollinations.ai（动态背景图）

## 🚀 快速开始

```bash
git clone https://github.com/knlit/elon-simulator.git
```

直接双击 `index.html` 在浏览器中打开即可游玩。

> 如需体验 AI 功能，在 `index.html` 中填入你的 Google Gemini API Key：
> ```js
> const apiKey = "YOUR_API_KEY_HERE";
> ```
